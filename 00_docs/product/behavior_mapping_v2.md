# Plant V2 行为与感知映射

## 1. 继承关系

V2 继承 [Plant V1 行为映射](behavior_mapping_v1.md) 的灯光和振动语义，但覆盖其舵机
语义：闭环舵机只负责生长高度。`WakeUp`、`Happy`、`Attention`、`Calm` 和 `Sleep`
不再产生机械目标，开始时只确保生长舵机停止并断电。

## 2. 位置反馈规则

| 行为 | 目标来源 | 完成条件 | 失败处理 |
| --- | --- | --- | --- |
| `WakeUp` | 无机械目标 | 舵机保持停止，灯光/振动自行推进 | 不改变生长高度 |
| `Happy` | 无机械目标 | 舵机保持停止，播放灯光/振动 | 不改变生长高度 |
| `Attention` | 无机械目标 | 舵机保持停止，播放灯光/振动 | 不改变生长高度 |
| `Calm` | 无机械目标 | 舵机保持停止，播放灯光 | 不改变生长高度 |
| `Sleep` | 无机械目标 | 立即停止 PWM 并关闭舵机电源 | 保留当前物理高度后进入轻睡眠 |
| `Error` | 不继续追逐运动目标 | 停止 PWM，并按机械设计保持或释放 | 错误路径不得再次自动运动 |
| `Grow` | 当前实测位置加一次安全增量 | 新绝对目标稳定到位 | 限幅、卡滞或反馈无效时拒绝 |
| `Retract` | 无互动衰减时从实测位置减一个小步长 | 新绝对目标稳定到位 | 不低于安全最小位置 |

相对的 `Grow`/`Retract` 只在本次运行中基于实测位置计算。复位后重新测量，不读取或
重放上一次命令。

## 3. 声学活动状态机

```text
Quiet
  │ 音量超过开启门限并持续达到最短时间
  ▼
Speaking
  │ 时间窗内讲话累计时间/占空比达到阈值
  ▼
SustainedSpeech
  │ 音量低于关闭门限并超过结束保持时间
  ▼
Quiet
```

开启门限高于关闭门限，避免临界音量导致状态抖动。`SustainedSpeech` 是持续声学活动
标签，不包含语义判断。

## 4. 执行器自噪声协调

| 条件 | 声学处理 |
| --- | --- |
| 舵机正在运动 | 继续读取音量用于诊断，但标记为受干扰，不累计讲话时间 |
| 振动马达正在工作 | 标记为受干扰，不累计讲话时间 |
| 执行器刚停止 | 在配置的恢复窗口内继续屏蔽 |
| LED、BLE、OTA 工作 | 正常检测；若样机验证发现干扰，再增加明确屏蔽规则 |
| 麦克风关闭或休眠 | 状态复位为 `Quiet`，停止采样 |

## 5. 四类互动到生长的映射

| 输入事件 | 立即反馈 | 生长申请条件 | 生长起点 |
| --- | --- | --- | --- |
| `BrightExposure` | 暖黄慢呼吸 | 有效照射累计达到一个时间片 | 当前实测位置 |
| `SpeechStarted` | 青蓝呼吸开始 | 不申请，只更新音量和状态 | — |
| `SustainedSpeechDetected` | 青蓝短增强 | 去重后的独立持续讲话边沿 | 当前实测位置 |
| 有效抚摸 | 绿色短脉冲 | 触摸防抖通过 | 当前实测位置 |
| `SuitableClimate` | 柔和粉白渐亮 | 温湿度同时适宜达到一个时间片 | 当前实测位置 |

四个来源的每个有效事件都向 Growth Service 提交一个 `GrowthCredit`。Growth Service
负责最多 4 个待处理量、执行器占用和到位确认，传感器 Service 不直接调用
Motion Port。

舵机不再执行普通行为；当 OTA、故障或上一高度动作占用执行器时，最多保留 4 个促进量。
队列只在 RAM 中保存，逐项执行或复位时清空，并从电位器重新读取实际位置。

连续 6 小时没有有效互动后提交内部 `InactivityDecay`，以后每小时下降 10/1000。新的
有效互动立即重置衰减计时。轻睡眠期间到期时临时唤醒完成一步 `Retract`，随后重新睡眠；
下降不播放 `GrowthRise`，也不低于安全最小位置。

轻睡眠期间麦克风关闭，但光照和温湿度继续低频推进。此时产生的环境促进进入同一个
最多 4 项的有界队列，不播放灯效、不驱动舵机；设备被触摸或 BLE 唤醒后再交给 Growth
Service 逐项处理。有效环境事件也会重置无互动衰减计时。

## 6. 光照状态机

```text
Dark / Ambient
  │ 相对光照超过开启门限并保持确认时间
  ▼
BrightExposure
  │ 累计达到有效照射时间片
  ├── 提交一次 GrowthCredit，记录一个有效时间片
  │ 相对光照低于关闭门限并保持退出时间
  ▼
Ambient / Dark
```

GL5528 只提供相对明暗。`BrightExposure` 是产品上的“晒太阳”，不代表固件识别了光源
类型。RGB 灯工作期间要防止自身光线改变判定。

## 7. 差异化灯效与优先级

| 场景 | Light Pattern | 说明 |
| --- | --- | --- |
| 晒太阳 | `SunGlow` | 暖黄/橙色慢呼吸 |
| 陪它说话 | `ListeningBreath` | 青蓝色，亮度跟随低频音量统计 |
| 抚摸 | `TouchPulse` | 绿色短脉冲 |
| 温湿度适宜 | `ComfortGlow` | 柔和粉白渐亮 |
| 执行生长 | `GrowthRise` | 绿色向暖白渐亮，到位后短暂保持 |
| 到达生长上限 | `GrowthLimit` | 暖白短双闪，不继续驱动舵机 |

灯效优先级为 `ErrorBlink` > `GrowthRise` > `TouchPulse` > `ListeningBreath` >
`ComfortGlow` > `SunGlow`。高优先级结束后重新根据当前传感状态选择背景灯效，不恢复
已过期的脉冲。

## 8. 产品事件映射

触摸、声学、光照和温湿度事件同时更新本地状态与 BLE 遥测：

- `SpeechStarted`：记录一次状态边沿，不中断当前行为。
- `SpeechEnded`：更新本轮讲话持续时间，不触发动作。
- `SustainedSpeechDetected`：上报一次去重事件并申请生长促进，不判断用户情绪或内容。
- `BrightExposureStarted/Ended`：更新晒太阳状态和暖黄背景灯效。
- `SuitableClimateReached/Left`：更新温湿度适宜状态，达到时间片后申请生长促进。
- `GrowthCreditEarned`：交由 Growth Service 决定立即执行、进入有界待处理队列或因容量
  已满而拒绝。
- `InactivityDecay`：无有效互动达到门限后按固定间隔产生一个较小的下降目标。

感知 Adapter 只产生测量值，不能直接决定 `Grow`、`Attention` 或灯光表现。

## 9. 系统优先级

环境感知事件低于触摸、BLE 明确命令、睡眠、OTA 和故障：

1. 故障与机械位置异常。
2. OTA、停止、睡眠和唤醒。
3. 用户触摸和 BLE 行为命令。
4. 已通过有效事件判定与限幅的生长促进。
5. 声学、光照状态与遥测更新。
6. 自动休眠超时。

声学检测不得唤醒深睡眠，也不得在 `Fault` 或 `Updating` 状态启动执行器。
