# Plant V2 行为与感知映射

## 1. 继承关系

V2 继承 [Plant V1 行为映射](behavior_mapping_v1.md) 的 `WakeUp`、`Happy`、
`Attention`、`Calm`、`Sleep` 和 `Error`。V2 的动作完成条件从“预计时间结束”升级为
“位置反馈稳定到位”；本文件只描述变化与新增规则。

## 2. 位置反馈规则

| 行为 | 目标来源 | 完成条件 | 失败处理 |
| --- | --- | --- | --- |
| `WakeUp` | 校准后的中立位置 | 实测位置连续进入中立容差带 | 停止舵机并产生 MotionFailure |
| `Happy` | 安全范围内的左右绝对目标序列 | 每段目标分别稳定到位，最后回中 | 任一段卡滞或超时即停止 |
| `Attention` | 安全抬头位置后回中 | 两段位置均稳定到位 | 停止并进入受控故障 |
| `Calm` | 校准后的中立位置 | 实测位置稳定到位 | 停止并报告偏差 |
| `Sleep` | 校准后的休眠位置 | 实测位置稳定到位后才断电 | 未到位不得进入低功耗 |
| `Error` | 不继续追逐运动目标 | 停止 PWM，并按机械设计保持或释放 | 错误路径不得再次自动运动 |
| `Grow` | 当前实测位置加一次安全增量 | 新绝对目标稳定到位 | 限幅、卡滞或反馈无效时拒绝 |
| `Retract` | 当前实测位置减一次安全增量 | 新绝对目标稳定到位 | 限幅、卡滞或反馈无效时拒绝 |

相对的 `Grow`/`Retract` 只在本次运行中基于实测位置计算。复位后重新测量，不读取或
重放上一次命令。

## 3. 声学活动状态机

```text
Quiet
  │ 音量超过开启门限并持续达到最短时间
  ▼
Speaking
  │ 时间窗内讲话累计时间/占空比达到阈值
  ▼
SustainedSpeech
  │ 音量低于关闭门限并超过结束保持时间
  ▼
Quiet
```

开启门限高于关闭门限，避免临界音量导致状态抖动。`SustainedSpeech` 是持续声学活动
标签，不包含语义判断。

## 4. 执行器自噪声协调

| 条件 | 声学处理 |
| --- | --- |
| 舵机正在运动 | 继续读取音量用于诊断，但标记为受干扰，不累计讲话时间 |
| 振动马达正在工作 | 标记为受干扰，不累计讲话时间 |
| 执行器刚停止 | 在配置的恢复窗口内继续屏蔽 |
| LED、BLE、OTA 工作 | 正常检测；若样机验证发现干扰，再增加明确屏蔽规则 |
| 麦克风关闭或休眠 | 状态复位为 `Quiet`，停止采样 |

## 5. 四类互动到生长的映射

| 输入事件 | 立即反馈 | 生长申请条件 | 生长起点 |
| --- | --- | --- | --- |
| `BrightExposure` | 暖黄慢呼吸 | 有效照射累计达到时间片且冷却结束 | 当前实测位置 |
| `SpeechStarted` | 青蓝呼吸开始 | 不申请，只更新音量和状态 | — |
| `SustainedSpeechDetected` | 青蓝短增强 | 去重边沿且冷却结束 | 当前实测位置 |
| 有效抚摸 | 绿色短脉冲 | 触摸防抖通过且冷却结束 | 当前实测位置 |
| `SuitableClimate` | 柔和粉白渐亮 | 温湿度同时适宜达到时间片且冷却结束 | 当前实测位置 |

四个来源都只向 Growth Service 提交一个 `GrowthCredit`。Growth Service 负责限幅、
冷却、过期、执行器占用和到位确认，传感器 Service 不直接调用 Motion Port。

当舵机正在执行高优先级行为时，最多保留一个有期限的促进量；多个来源不会堆成一串
待执行动作。复位会清空待处理促进量，并从电位器重新读取实际位置。

轻睡眠期间麦克风关闭，但光照和温湿度继续低频推进。此时产生的环境促进只合并保留
一个，不播放灯效、不驱动舵机；设备被触摸或 BLE 唤醒后再交给 Growth Service 处理。

## 6. 光照状态机

```text
Dark / Ambient
  │ 相对光照超过开启门限并保持确认时间
  ▼
BrightExposure
  │ 累计达到有效照射时间片
  ├── 提交一次 GrowthCredit，进入冷却
  │ 相对光照低于关闭门限并保持退出时间
  ▼
Ambient / Dark
```

GL5528 只提供相对明暗。`BrightExposure` 是产品上的“晒太阳”，不代表固件识别了光源
类型。RGB 灯工作期间要防止自身光线改变判定。

## 7. 差异化灯效与优先级

| 场景 | Light Pattern | 说明 |
| --- | --- | --- |
| 晒太阳 | `SunGlow` | 暖黄/橙色慢呼吸 |
| 陪它说话 | `ListeningBreath` | 青蓝色，亮度跟随低频音量统计 |
| 抚摸 | `TouchPulse` | 绿色短脉冲 |
| 温湿度适宜 | `ComfortGlow` | 柔和粉白渐亮 |
| 执行生长 | `GrowthRise` | 绿色向暖白渐亮，到位后短暂保持 |
| 到达生长上限 | `GrowthLimit` | 暖白短双闪，不继续驱动舵机 |

灯效优先级为 `ErrorBlink` > `GrowthRise` > `TouchPulse` > `ListeningBreath` >
`ComfortGlow` > `SunGlow`。高优先级结束后重新根据当前传感状态选择背景灯效，不恢复
已过期的脉冲。

## 8. 产品事件映射

触摸、声学、光照和温湿度事件同时更新本地状态与 BLE 遥测：

- `SpeechStarted`：记录一次状态边沿，不中断当前行为。
- `SpeechEnded`：更新本轮讲话持续时间，不触发动作。
- `SustainedSpeechDetected`：上报一次去重事件并申请生长促进，不判断用户情绪或内容。
- `BrightExposureStarted/Ended`：更新晒太阳状态和暖黄背景灯效。
- `SuitableClimateReached/Left`：更新温湿度适宜状态，达到时间片后申请生长促进。
- `GrowthCreditEarned`：交由 Growth Service 决定立即执行、保留一个待处理量或丢弃。

感知 Adapter 只产生测量值，不能直接决定 `Grow`、`Attention` 或灯光表现。

## 9. 系统优先级

环境感知事件低于触摸、BLE 明确命令、睡眠、OTA 和故障：

1. 故障与机械位置异常。
2. OTA、停止、睡眠和唤醒。
3. 用户触摸和 BLE 行为命令。
4. 已通过冷却与限幅的生长促进。
5. 声学、光照状态与遥测更新。
6. 自动休眠超时。

声学检测不得唤醒深睡眠，也不得在 `Fault` 或 `Updating` 状态启动执行器。
