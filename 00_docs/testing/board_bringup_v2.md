# Plant V2 上板验证清单

## 1. 基线

先完成 [Plant V1 上板验证](board_bringup_v1.md)，再启用 V2 感知硬件。参考电路见
[Plant V2 低成本感知硬件方案](../product/hardware_sensing_v2.md)。主机测试和交叉编译
不能替代以下实测。

## 2. 上电前检查

- 确认三路 ADC GPIO 属于目标 ESP32-C3 模组可用 ADC 通道，未占用 Flash、USB 或启动脚。
- 确认电位器两端不会超过 ADC 电压范围，机构全行程不会撞到电气端点。
- 确认 ECM 极性、2.2 kΩ 偏置、运放供电/共模范围和包络输出最大电压。
- 确认 GL5528 分压方向、固定电阻和 RGB 遮光结构。
- 确认 AHT21 地址、I²C 上拉、去耦、通风孔和热源距离。
- 确认 5050 RGB 与 0827 马达均有外部驱动，马达有续流/钳位保护。
- 确认 TP4056 充电电流适合 300–500 mAh 电芯，并有电芯保护、负载共享和舵机峰值
  电流路径；不得把 TP4056 当作完整电源管理芯片。
- 确认 GPIO18/19 未连接板载外设，原生 USB Serial/JTAG 能在运行期持续枚举并输出日志。
- 确认 GPIO2/9 的 I²C 上拉在正常复位时保持高电平，AHT21/MAX17048 不会在启动采样期
  拉低总线；按住 GPIO9 BOOT 后复位仍必须可靠进入 USB/UART 下载模式。
- 确认 GPIO20/21 与 UART0 下载夹具的隔离。
- 测量 GPIO8 麦克风电源和 GPIO10 舵机电源外部上下拉，确认不会改变 ESP32-C3 的启动
  绑带状态；同时检查上电、下载和 Bootloader 日志期间马达不会误动作。
- 断开 TTP223 时确认 GPIO21 的弱下拉使输入保持未触摸，至少运行 15 秒不得误触发本地
  恢复或清除 BLE 绑定；接回推挽输出后再验证高电平触摸可靠覆盖弱下拉。
- 首次舵机联调卸下连杆或限制负载，并使用限流电源。

## 3. 位置反馈

1. 手动缓慢走完整个机械行程，记录 ADC 最小、最大、单调性和噪声峰峰值。
2. 校准生长安全最小、最大位置，机械端点外保留余量。
3. 验证 WakeUp、Happy、Attention、Calm 和 Sleep 均不改变舵机位置；再分别验证 Grow
   和无互动 Retract 的到位条件。
4. 断开电位器滑动端、短接到地/电源，确认舵机立即停止且不继续增长。
   静止时用可控方式注入单个越界毛刺，确认不会进入 `Fault`；连续三个异常必须
   确认故障。运动过程中首个异常仍必须立即停止输出。
5. 人为阻挡机构，验证无位移和超时检测；用限流避免真实堵转损坏。
6. 在任意高度复位，确认只读取当前位置，不重放上一次命令。
7. 舵机断电后施加轻微外力，记录机构是否自保持；不自保持时不得宣称断电保持高度。

## 4. ECM 与讲话活动

1. 在安静环境记录包络底噪，不得连续贴近 0 或 ADC 满量程。
2. 在固定距离测试轻声、正常讲话和较大声讲话，记录相对音量区间。
3. 验证短促敲击不进入 `SustainedSpeech`，连续讲话满足时间窗后只产生一次促进量。
4. 单独运行舵机、振动、RGB 和 BLE，确认自噪声屏蔽与恢复时间足够。
5. 检查 BLE、日志和 Flash 中没有原始音频或连续音量流。
6. 关闭麦克风和进入睡眠后确认采样停止，并测量模拟前端电流。

## 5. GL5528

1. 分别记录遮黑、普通室内、靠窗明亮和强灯照射的 ADC 分布。
2. 调整双门限和确认时间，验证手影、开关灯瞬态不会抖动。
3. 逐一播放所有 RGB 颜色和最大允许亮度，确认不会自激成“晒太阳”。
4. 持续明亮每达到一个完整时间片只产生一次促进量，时间片内不重复。
5. 断开或短接分压，确认报告传感器故障且不促进生长。

## 6. AHT21 温湿度

1. 上电检查校准状态、地址 `0x38`、busy 位、CRC 和有限重试。
2. 与一只可信温湿度计在至少三个环境点对比，记录整机安装误差。
3. 对传感器轻微加热、降温、增湿和干燥，验证迟滞状态转换。
4. 温度和湿度必须同时适宜并持续达到时间片，才产生一次促进量。
5. 断开 SDA/SCL、制造 CRC 错误，确认进入 `SensorFault` 且不促进生长。
6. 运行舵机、RGB 和电源满载，确认 PCB 自热不会把环境误判为适宜。

## 7. 充电、电池与电量计

1. 分别在 USB 供电、仅电池供电及边充边运行时验证负载共享，不允许系统负载破坏
   TP4056 的充满判定。
2. 测量 TP4056 充电电流与温升，确认不超过最终电芯规格和 PCB 热设计。
3. 验证电芯过充、过放、短路保护，并用限流电源验证舵机堵转不会导致 MCU 反复复位。
4. 用万用表对比 MAX17048 电压，覆盖正常、低电和临界电量状态；拔掉 I²C 后应报告
   `SensorFault`，不得伪造电量。
5. 确认 `CHRG`/`STDBY` 未接入时 BLE 不报告充电状态。

## 8. 四类生长与灯效

| 来源 | 预期灯效 | 预期运动 |
| --- | --- | --- |
| 抚摸 | 绿色短脉冲 | 每次通过防抖的有效触摸增长一步 |
| 持续讲话 | 青蓝音量呼吸/短增强 | 去重后增长一步 |
| 持续明亮 | 暖黄慢呼吸 | 时间片达标后增长一步 |
| 温湿度适宜 | 柔和粉白渐亮 | 时间片达标后增长一步 |

- 连续提交四个有效来源时逐个增长，待处理量最多为 4；第五个不得造成越界或无限积压。
- 使用缩短的测试配置验证无互动衰减：到期只下降一个小步长、新互动重置计时、轻睡眠中
  衰减完成后自动回到轻睡眠，且不低于安全最小位置。
- 到达生长上限后只给 `GrowthLimit` 灯效，不继续输出顶住端点的 PWM。
- 故障、OTA、Sleep 和 Stop 能中断或拒绝所有促进动作。
- 拔掉位置反馈使设备进入 `Fault` 后，已绑定客户端仍能开始恢复 OTA；传输取消或断连后
  设备保持 `Fault`，完整镜像则进入重启与自检/回滚流程。
- 复位后待处理促进量和衰减计时清空，实际位置从电位器重新建立。

## 9. 稳定性与寿命

- 四类来源各触发至少 500 次，记录误报、漏报和灯效优先级错误。
- Grow/Retract 循环至少 1000 次，检查电位器磨损、机构回差和舵机温升。
- 连续运行 24 小时，覆盖昼夜光照、温湿度变化和多人讲话环境。
- 进入轻睡眠后确认麦克风前端关闭，GL5528、AHT21 与电量仍按低频周期更新；睡眠期间
  达标的环境促进不驱动输出，触摸唤醒后最多执行一次。
- 逐一断开 ECM、GL5528、AHT21 和 MAX17048，确认对应能力降级且 BLE/OTA/其余交互
  仍可用；位置反馈断线必须继续阻止机械动作和启动确认。
- 复位和断连后验证 30 秒 100–150 ms 快速广播，再退到 500–1000 ms 慢速广播；分别在
  安静和拥挤射频环境记录发现 P50/P95。
- 分别测量活动、传感监测轻睡眠和深睡眠电流；首版深睡默认关闭，只有完成准入测试后
  才允许在产品配置启用。

## 10. 生产 OTA 签名准入

根目录 `sdkconfig.defaults` 是开发联调配置，不启用密码学镜像验证，启动日志会明确提示。
生产候选构建必须叠加 `10_config/plant_v2/sdkconfig.ota-signing.defaults`：

```bash
idf.py -B /tmp/plant-v2-signed-build \
  -D PLANT_PRODUCT=v2 \
  -D SDKCONFIG=/tmp/plant-v2-signed-sdkconfig \
  -D SDKCONFIG_DEFAULTS="sdkconfig.defaults;10_config/plant_v2/sdkconfig.ota-signing.defaults" \
  build
```

该配置故意不把私钥路径写入仓库，也不在普通构建机自动签名。将未签名镜像交给受控签名
环境后执行：

```bash
idf.py -B /tmp/plant-v2-signed-build secure-sign-data \
  --keyfile /secure/plant-v2-ota-signing-key.pem \
  --output /tmp/plant_v2_signed.bin \
  /tmp/plant-v2-signed-build/plant_v2.bin
idf.py -B /tmp/plant-v2-signed-build secure-verify-signature \
  --keyfile /secure/plant-v2-ota-signing-key.pem \
  /tmp/plant_v2_signed.bin
```

私钥必须由产品负责人确定生成、备份、访问控制、轮换和撤销策略，不能提交到 Git。首次
建立信任的设备也必须运行使用同一可信签名体系构建并签名的应用。上板至少验证：合法签名
升级成功、任意改动一个字节被拒绝、错误密钥被拒绝、传输中断保持旧固件、启动自检失败
触发回滚。是否进一步烧录 Secure Boot/eFuse 属于不可逆生产决策，必须单独评审。
